# 로비 HUD

- `Assets/_Scripts/Resources/UI/LobbyHudUI.prefab`이 실제 화면 배치입니다. `LobbyHudUI : UIBase`가 표시하고 `RoomHudPresenter`가 기존 UIManager를 통해 로비/인게임 프리팹을 전환합니다. 새 Canvas나 UI 컨트롤을 런타임에 만들지 않습니다.
- 방 입장 성공 시 로비 HUD가 표시됩니다. 기본 로비 제한 시간은 30초이며 프리팹 `LobbyHudUI > Duration Seconds`에서 변경합니다. UI를 다시 열어도 카운트다운을 재시작하지 않습니다. 0초에서 멈추고 서버의 `S_OpenDoor(Kitchen)` 또는 `S_StageStart`를 기다립니다. 클라이언트가 시간 만료로 시작 패킷을 보내지 않습니다.
- 현재 프로토콜에 로비 남은 시간이 없으므로 입장 수신 시각 기준입니다. 나중에 서버에서 남은 시간을 받으면 `RoomHudSession.Instance.SetLobbyRemainingSeconds(remainingSeconds)`로 보정합니다. 이 정보가 없으면 후입장자와 기존 플레이어의 표시 초까지 같게 보장할 수 없습니다.
- 실제 시작 알림에서 로비 HUD를 숨기고 인게임 HUD를 엽니다. 인게임 시계가 먼저 들어오고 정보 영역이 뒤따르는 기존 애니메이션을 사용합니다. Tab 테스트도 같은 전환을 따르며, 테스트 단축키로 주방 문을 비활성화하는 기능은 유지합니다.
- `S_OpenDoor(Lobby)`를 받으면 로비 화면과 카운트다운을 다시 표시합니다. 결산 화면은 아직 구현하지 않았으며, 결산 후 로비 복귀도 이 알림에 연결할 수 있습니다.
- 방 코드는 입장 패킷의 RoomId입니다. Q 또는 눈 버튼으로 내 화면에서만 코드를 숨기거나 표시합니다. 텍스트 입력 중에는 Q를 단축키로 소비하지 않습니다.
- 참가자 표시는 입장 순서의 `참가자 1`, `참가자 2`입니다. 현재 2인 방 프로토콜의 기존 플레이어/신규 플레이어 순서를 사용하고 입·퇴장 시 갱신합니다. 보유 황금 콩은 기존 `S_RoomMoney` 잔액을 사용합니다.

## 마이크 입력 아이콘

- 음파 없는 스피커와 음파 있는 스피커 Sprite를 프리팹에 연결했습니다. 참가자별 상태는 `LobbyHudState`에서 보관합니다.
- `LobbyMicrophoneActivity`는 내 기본 마이크를 감지해 임계값 이상의 입력이 있을 때 음파 아이콘으로 전환합니다. 입력이 없으면 잠깐의 해제 지연 뒤 기본 아이콘으로 돌아갑니다. 녹음 파일이나 음성 송신 기능을 만들지 않으며, HUD가 닫히면 이 컴포넌트가 시작한 마이크 캡처만 종료합니다.
- 다른 음성 모듈이 이미 마이크를 사용하고 있다면 별도 캡처를 시작하지 않습니다. SDK를 연결할 때는 프리팹의 `Monitor Local Microphone`을 끄고, **내 입력과 상대방 입력 모두** 아래 API로 전달하면 됩니다.

```csharp
RoomHudSession.Instance.SetPlayerSpeaking(playerId, hasMicrophoneInput);
```

- 현재 제공된 프로토콜에는 상대 마이크 상태가 없으며 음성 SDK도 확인되지 않았습니다. 따라서 상대 아이콘의 실제 변화에는 해당 SDK/통신 연결이 필요합니다. 입력을 받지 않은 참가자는 기본 아이콘을 표시합니다. 서버 스크립트와 패킷 정의는 수정하지 않았습니다.
